# AI vs 원숭이 vs 존버

DeepSeek이 직접 종목을 골라 가짜 돈으로 주식을 굴리는 모의투자 리그. 한국 주식과 미국 주식에서 따로 겨룬다.

| 선수 | 하는 일 |
|---|---|
| AI (DeepSeek) | 시총 상위 후보(한국 110개, 미국 120개)를 보고 15개로 추린 뒤, 뉴스와 지표를 읽고 최대 10종목의 비중과 계획(손절·목표·트레일링)을 정한다. 장중에는 상황을 보면서 비중과 계획을 계속 고친다 |
| 원숭이 | 같은 후보에서 5종목을 무작위로 골라 똑같이 나눠 산다. 결정 5번마다 새로 찍는다 |
| 존버 | 첫날 지수 ETF(한국 KODEX 200, 미국 SPY)를 사서 계속 들고 간다 |

시작 자금은 한국 1억원, 미국 10만 달러.

## 두 가지 모드

**하루 한 번 (`run`)**: 장이 끝난 뒤 그날 종가까지 보고 내일 주문을 정한다. 주문은 다음 거래일 시가에 체결된다.

**장중 실시간 (`live`)**: 장이 열려 있는 동안 계속 지켜보면서 반응한다. 끄기 전까지 계속 도는 프로그램이고, 장이 끝나면 `run`이 하던 하루 정산과 내일 주문 결정까지 알아서 이어서 한다.

### 실시간 모드가 일하는 방식

AI를 계속 부르면 느리고 비싸서, 싼 일은 코드가 하고 판단이 필요한 일만 AI가 한다.

| 하는 일 | 주기 | AI 호출 |
|---|---|---|
| 시총 상위 200종목 시세 확인 | 20초 | 없음 |
| AI가 정해둔 계획 확인: 손절, 따라 올라가는 손절, 목표가 매도 | 20초 | 없음 (닿으면 바로 팔고, 판 뒤에 AI를 부름) |
| AI가 걸어둔 가격 알림 확인 | 20초 | 울리면 호출 |
| 보유 종목이 평소보다 빠르게 움직였는지 확인 | 20초 | 사건이 생기면 호출 |
| 보유·후보·급등락 종목 뉴스, 시장 주요뉴스, 보유 종목 거래소 공시 확인 | 2분 | 새 기사가 있으면 빠른 모델이 먼저 거르고, 중요할 때만 큰 모델 호출 (기사만으로는 매매 없음, 아래 참고) |
| 장 시작 점검 | 장 열리고 15분 뒤 한 번 (첫 15분의 소란은 넘긴다. 그동안 생긴 급변·등락 사건은 모아 뒀다가 이때 같이 본다) | 호출 |
| 아무 일 없어도 정기 점검 | AI가 정한 간격 (15~120분, 기본 90분) | 호출 |

### AI는 한 번 정한 걸 고집하지 않는다

점검 때마다 AI가 쓸 수 있는 도구:

- **비중 바꾸기**: 조금 사고 상황을 보면서 더 사거나(분할 매수), 일부만 팔 수 있다(분할 매도).
- **계획 고치기**: 매매 없이 계획만 바꿀 수 있다. 수익이 나면 손절가를 평단 위로 올려서 이익을 지키는 식이다.
  - 손절가: 이 아래로 내려가면 전량 매도
  - 목표가와 매도 비율: 닿으면 정한 비율만 판다 (0.5면 절반). 팔고 나면 AI를 불러서 남은 물량 계획을 다시 정하게 한다
  - 따라 올라가는 손절(트레일링): 오른 뒤 최고가에서 정한 비율만큼 빠지면 전량 매도
  - 손절도 트레일링도 없으면 기본 손절이 걸린다. 폭은 그 종목 하루 변동성의 3.5배(5~15%)라서 조용한 종목은 좁게, 출렁이는 종목은 넓게 걸린다. 더 사서 평단이 오르면 따라 오르지만, 떨어질 때 더 사서(물타기) 평단이 내려가도 손절가는 내려가지 않는다. AI가 직접 정한 손절가는 그대로 있다.
- **가격 알림**: "95원 아래로 오면 더 살지 검토"처럼 가격과 메모를 걸어두면, 그 가격에 닿을 때 메모와 함께 AI를 다시 부른다. 최대 10개, 한 번 울리면 사라진다.
- **다음 점검 시간**: 불안하면 15분 뒤, 조용하면 2시간 뒤처럼 AI가 스스로 정한다.

### 수수료가 새지 않게 막는 장치

AI는 물어보면 뭔가 하려는 경향이 있어서, 자주 사고팔다 수수료와 미끄러짐으로 새지 않게 코드가 한도를 건다. 손절·목표가 같은 자동 집행은 이 한도와 상관없이 항상 돈다.

- 하루 장중 매수는 평가금액의 30%까지. 손절로 판 돈을 바로 다시 쓰는 걸 막는다.
- 오늘 판 종목은 오늘 다시 사지 않는다. 산 지 30분이 안 된 종목은 AI가 팔 수 없다.
- 오늘 3% 넘게 잃으면 그날은 새로 사지 않는다 (파는 건 된다).
- 장중에 새로 살 수 있는 건 보유 종목과 전날 조사해 둔 후보뿐이다. 그날 많이 오른 종목은 분위기 참고로만 보여준다.
- 한 업종에는 합쳐서 40%까지만 담는다. 하루 결정 때는 넘친 업종을 같은 비율로 줄이고, 장중에는 넘게 사지 못하게 한다. 미국은 '반도체'와 '반도체 장비'처럼 잘게 나뉜 업종을 한 묶음으로 센다.
- 장 시작 뒤 15분과 마감 10분 전(한국은 종가 동시호가)에는 AI가 새로 사지 않는다.
- AI가 생각하는 동안(1~2분) 가격이 2% 넘게 움직였으면 그 답으로는 매매하지 않는다. 매도는 지금 가격으로 한 번 더 물어본다. 답이 5분 넘게 늦게 오면 매매는 버리고 계획만 받는다.
- AI가 생각하는 동안 손절·목표가로 팔린 종목은 그 답으로 다시 사지 않는다.
- AI한테는 다른 선수들의 순위를 보여주지 않는다. 지고 있다고 무리하지 않게.

### 기사 하나로는 사고팔지 않는다

뉴스는 틀리거나 소문일 수도 있다. 그래서 기사만 보고는 매매하지 않고, 주가가 확인해준 다음에 움직인다.

- 주가 움직임 없이 기사만 들어오면 **뉴스 점검**이 된다. 이때 AI는 사고팔 수 없고 준비만 한다.
  - 손절 조이기: 지금 가격보다 2% 넘게 아래까지만. 손절을 가격에 바짝 붙여서 사실상 파는 걸 막는다. 목표가와 트레일링도 같은 간격 제한을 받는다.
  - 알림 걸기: 지금 가격에서 2% 넘게 떨어진 가격만. 원래 걸려 있던 알림은 그대로 다시 걸 수 있다.
  - 다시 보기: 15분 뒤에 기사가 나온 뒤로 주가가 시장 대비 얼마나 움직였는지 보여주고 다시 물어본다. 매매는 그때 할 수 있다.
- AI가 뉴스 점검에서 사고팔려고 하면 그 매매는 미루고, 15분 뒤 다시 보기를 자동으로 건다.
- 다시 보기 전에 그 종목이 급변하거나 알림·손절이 울리면 15분을 기다리지 않는다. 주가가 이미 확인해준 셈이라 그 기사와 같이 바로 보여준다.
- 주가가 먼저 움직인 종목(급변, 알림 등)은 그 종목 기사를 매매 점검에 같이 넣는다.
- 기사마다 믿을 만한지 판단할 힌트를 붙인다: 최근 1시간 그 종목 기사 수와 매체 수, 앞서 나온 기사 제목, '~설'·'단독'·'검토'·'가능성' 같은 추측성 표현, 기사 뒤 주가 변화. 판단은 AI가 한다.
- 뉴스를 먼저 거르는 빠른 모델도 한 매체만 쓴 소문은 웬만하면 넘기고, 하루 결정 때도 기사 하나만 보고 크게 걸지 말라고 알려준다.

안전장치:

- 급변 기준은 종목마다 다르다. 최근 15분 움직임이 그 종목의 평소 변동폭(일봉 20일 변동성 기준)의 3배를 넘고 1.2% 이상일 때만 사건으로 친다.
- '오늘 +3% 넘었다' 같은 등락 단계 사건은 단계마다 하루 한 번만 울린다. 경계에서 오르내려도 다시 울리지 않고, 더 높은 단계나 반대쪽 단계에 처음 닿을 때만 새 사건이 된다.
- 큰 모델은 별도 스레드에서 생각한다. 생각하는 동안에도 시세 확인과 손절은 멈추지 않는다.
- 체결은 AI 답이 돌아온 그 순간의 시세로 한다. AI가 볼 때보다 2% 넘게 오른 종목은 추격매수하지 않는다.
- 손절·목표가는 그 가격을 넘은 시세가 두 번 연속(약 40초) 확인될 때만 집행한다. 튀는 시세에 팔지 않으려는 것. 다만 2% 넘게 뚫었으면 급락이라 보고 바로 판다.
- 상한가 종목은 사지 않고, 하한가에서는 손절이 체결되지 않은 걸로 친다 (풀리면 바로 판다).
- 지금 가격보다 높은 손절가, 지금 가격보다 낮은 목표가, 걸자마자 팔리는 트레일링, 바로 울릴 알림은 받지 않고 이유를 기록에 남긴다.
- 하루 한도: AI 점검 20번, 뉴스 심사 80번, 실시간 매매 30건. AI한테 남은 점검 횟수를 알려줘서 스스로 아껴 쓰게 한다. 다 쓰면 그날은 손절·목표가·트레일링만 자동으로 돌아간다.
- AI 호출이 실패하면 중요한 사건(손절, 알림 등)은 한 번 더 물어본다. 뉴스는 버린다. AI 호출 한 번은 최대 2분 반까지만 기다린다.
- 거래정지 종목, 마지막 체결이 15분 넘게 오래된 종목은 거래하지 않는다.
- 장이 열렸는지는 지수 ETF 시세로 본다. 넥스트레이드 시간외(08:00~08:50, 15:30~20:00)에는 개별 종목이 '거래 중'으로 나오지만 ETF는 거기서 거래되지 않아서 속지 않는다. 새해 첫날·수능일처럼 늦게 열거나 늦게 끝나는 날도 실제 시세를 보고 따라간다. 3시간 넘게 안 열리면 휴장일로 본다.
- 엔진을 껐다 켜도 그날 기록(장 시작 점검 여부, 오늘 등락 단계, 뉴스 다시 보기 예약, 최근 시세)을 이어받는다.
- 하루 정산 때 오늘 일봉이 아직 안 올라왔으면 넘기지 않고 10분마다 다시 한다 (마감 뒤 4시간까지).
- 시가 봉이 늦게 오는 종목은 다른 곳에서 시가를 구해서 체결하고, 그래도 못 구하면 못 산 종목을 기록과 화면에 남긴다.
- 오늘 기준가가 어제 적어 둔 종가와 가격제한폭 넘게 다르면(분할이 아직 반영 안 된 경우) 장부를 고칠 때까지 그 종목 손절을 멈춘다.

솔직한 한계: 초 단위 매매가 아니다. 사건이 생긴 뒤 반응하기까지 대략 20초(시세 확인 주기)에 AI가 답하는 시간(몇 초에서 1분)이 걸린다. 분 단위 반응이다.

## 공통 규칙

- 결정은 그 시점에 알 수 있는 정보로만 한다. 장 마감 뒤 결정은 확정된 종가까지, 장중 결정은 그 순간의 시세와 뉴스까지.
- 하루 한 번 모드에서 장중에 돌리면 그날 장 시작 전에 나온 뉴스까지만 AI한테 보여준다.
- 과거 데이터로 백테스트는 하지 않는다. AI가 학습 때 이미 과거 주가를 봤을 수 있어서, 앞으로의 날짜로만 실력을 잰다.
- 비용은 `trader/config.py`의 대략적인 가정값이다. 한국은 수수료 0.015% + 매도세 0.20% (2025년 세법 개정으로 2026년부터 0.20%), 미국은 수수료 0.07%. 여기에 체결가가 불리한 쪽으로 어긋나는 미끄러짐을 붙인다: 한국 0.05%, 미국 0.03%와 호가 반 칸 중 큰 쪽. 싼 주식일수록 호가 한 칸이 비싸서 더 밀린다. 호가창을 못 보니까 실제와 다를 수 있다.
- 액면분할·병합·무상증자로 가격 기준이 바뀌면 (네이버 일봉이 소급해서 고쳐지거나 오늘 기준가가 달라지면) 세 선수 모두 주식 수와 평단, 손절가, 알림 가격을 같은 비율로 고친다. 끝수 주식은 현금으로 정산한다.
- 배당은 날짜별 배당락 정보를 모든 종목에 대해 구하기 어려워서, 연 배당수익률을 거래일마다 1/252씩 현금으로 넣는다. 길게 보면 배당락 날 빠지는 만큼을 채워 준다. SPY는 배당수익률을 못 받아서 1.2%로 둔다.
- AI한테 다가오는 일정도 보여준다: FOMC(연준 홈페이지), 옵션 만기일(계산), 미국 실적 발표일(나스닥 실적 캘린더). 한국 종목은 거래소 공시(투자경고, 공매도 과열 등)도 같이 본다.
- 시세·시총 순위·뉴스·공시·업종은 네이버 증권의 비공식 주소에서 키 없이 받아온다. 개인 실험용이고, 네이버가 바꾸거나 막으면 멈출 수 있다.
- 순위 차이가 실력인지 운인지: 대시보드에 두 선수 하루 수익률 차이의 흔들림으로 계산한 '운으로도 나올 수 있는 폭'을 같이 보여준다. 몇 주 안의 차이는 대부분 운이다.

## 돌리기

Python 3.10 이상. 표준 라이브러리만 쓴다. 윈도우는 시간대 데이터가 없어서 `pip install -r requirements.txt`를 한 번 해야 한다.

```bash
export DEEPSEEK_API_KEY=sk-...       # 프록시가 키를 넣어주는 환경이면 생략
python -m trader live                # 장중 실시간 감시 (한국·미국 둘 다, 끄기 전까지 계속)
python -m trader live --market kr    # 한국만
python -m trader live --serve 8765   # 감시하면서 실시간 대시보드도 띄운다 (http://127.0.0.1:8765)
python -m trader serve               # 대시보드만 (엔진을 따로 돌리고 있을 때)
python -m trader run                 # 하루 정산과 내일 주문 결정을 지금 한 번
python -m trader report              # report/index.html 대시보드 생성
python -m unittest discover -s tests # 테스트 (네트워크 안 씀)
```

`live`가 돌고 있는 동안에는 `run`을 따로 돌리지 않는다. 같은 상태 파일을 둘이 같이 고치게 된다.

대시보드는 보는 기기에 맞춰 모양이 바뀐다. PC(가로 1024px 이상)는 본문 옆에 실시간 칸이 따라다니고, 태블릿은 한 줄로 쭉, 폰은 아래 탭(순위·실시간·AI·보유)으로 한 칸씩 본다. 테마는 오른쪽 위에서 자동·밝게·어둡게를 고를 수 있고, 고른 건 그 브라우저에 남는다.

### 어디서 돌려야 하나

`live`는 장이 열린 시간 내내 켜져 있어야 한다.

- 한국장: 09:00~15:30 (한국시간)
- 미국장: 밤 22:30~05:00 (서머타임), 23:30~06:00 (겨울)

켜둔 PC, 라즈베리파이, 작은 서버(VPS)에서 돌리면 된다. 클라우드 개발 환경처럼 일정 시간 안 쓰면 회수되고 백그라운드 실행 시간에도 제한이 있는 곳은 상시 실행용으로 맞지 않는다. GitHub Actions 같은 주기 실행은 최소 간격이 5분이고 제때 안 도는 일도 많아서 실시간 감시에는 못 쓴다.

### 윈도우 PC에서 켜기

1. [python.org](https://www.python.org)에서 Python을 설치한다. 설치 화면에서 "Add python.exe to PATH"를 체크한다.
2. DeepSeek API 키를 만들어서 명령 프롬프트에 `setx DEEPSEEK_API_KEY sk-여기에키` 를 한 번 입력한다. 새 창을 열어야 적용된다.
3. 이 폴더의 `start_live.bat`을 더블클릭한다. 필요한 걸 설치하고, 실시간 감시를 시작하고, 브라우저에 대시보드가 열린다.
4. 장이 열려 있는 동안 PC가 절전에 들어가면 감시가 멈춘다. 전원 설정에서 절전을 꺼둔다.

상태는 `state/` 폴더에 쌓인다. 다른 곳에 남기고 싶으면 가끔 커밋해서 올려두면 된다.

| 경로 | 내용 |
|---|---|
| `trader/data.py` | 네이버 증권 일봉, 시총 순위, 뉴스, 기본 지표 |
| `trader/quotes.py` | 장중 실시간 시세 스냅샷과 최근 시세 기록 |
| `trader/triggers.py` | '지금 AI를 깨울 일인가'를 정하는 순수 함수 |
| `trader/brain.py` | DeepSeek 프롬프트와 응답 정리 (하루 결정, 뉴스 심사, 장중 판단) |
| `trader/agenda.py` | 다가오는 일정: FOMC, 옵션 만기, 미국 실적 발표 |
| `trader/corp.py` | 분할·병합 반영과 배당 쌓기 |
| `trader/plans.py` | 종목별 계획: 손절가, 목표가와 매도 비율, 따라 올라가는 손절 |
| `trader/broker.py` | 가짜 증권사: 체결, 수수료, 세금, 미끄러짐 |
| `trader/league.py` | 하루 정산: 체결 → 평가 → 결정 |
| `trader/live.py` | 장중 실시간 엔진 |
| `trader/report.py` | 대시보드 데이터 모으기와 HTML 생성 |
| `trader/serve.py` | 로컬 실시간 대시보드 서버 (5초마다 갱신) |
| `start_live.bat` | 윈도우에서 한 번에 켜는 파일 |
| `state/kr.json`, `state/us.json` | 리그 상태 (포트폴리오, 매매 기록, 판단 일지, 손절 계획) |
| `logs/<시장>/<날짜>.json` | 그날 AI 응답 원문과 토큰 사용량 |
| `runtime/` | 실시간 엔진이 계속 쓰는 임시 파일 (시세 스냅샷, 이벤트 피드, 분 단위 평가금액, 재시작용 그날 기록). git에는 안 올린다 |
| `state/calendar.json` | FOMC 일정 캐시 (하루 한 번 새로 받는다) |

전부 가짜 돈으로 하는 실험이다. 여기 나오는 종목은 투자 추천이 아니다.
